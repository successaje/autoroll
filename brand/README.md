# Brand

Everything here is generated by `make.py` — edit that, not the SVGs, and
re-render with `python3 make.py`.

## The mark

A ring of ten discrete segments. Each segment is one expiring window; the ring
is the position that outlives them. Opacity falls off behind the leading edge so
it reads as a roll in motion rather than a static dial, and one segment is
orange because the book has two sides and a run takes both.

It is deliberately close to a progress spinner. That is the idea — something
that keeps going on its own, with no one watching it.

## Files

| File | Use |
|---|---|
| `logo-mark-*.png` | Square icon, transparent. 32–1024. |
| `logo-mark-dark-*.png` | Same on the app's near-black ground, rounded. App icons, avatars. |
| `logo-wordmark-*.png` | Mark + name, transparent. |
| `logo-wordmark-dark-*.png` | Same on the dark ground. |
| `og-card.png` | 1200×630 social/preview card. |
| `*.svg` | Vector sources — scale these rather than upscaling a PNG. |

Use a transparent variant on a light ground; the wordmark type is near-white and
will disappear.
